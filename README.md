<h1>🪐 Interactive Solar System</h1>
<p>An Interactive <strong>3D Solar System</strong> built with <strong>JavaScript and Three.js</strong></p>
<p>▶ <a href="https://adamfeher3.github.io/solar-system-three.js/">LIVE DEMO</a></p>
<h2>🎯 About the Project</h2>
<p>
  This project was created as a personal learning experience to improve my programming skills, explore 3D development with Three.js, and gain hands-on experience with JavaScript
</p>
<h2>⚙ Features</h2>
<ul>
  <li><strong>Planet Selection</strong> — Select individual planets to explore the Solar System</li>
  <li><strong>Planet Information</strong> — View a short description of the currently selected planet</li>
  <li><strong>Orbital Navigation</strong> — Orbit the camera around a selected planet to explore it from different angles</li>
  <li><strong>Zoom Controls</strong> — Zoom in for a closer look or zoom out to get a broader view</li>
  <li><strong>Planetary Rotation</strong> — Observe planets rotating around their own axes</li>
  <li><strong>Orbit Visualization</strong> — Toggle planetary orbit paths on and off</li>
  <li><strong>Real-Time 3D Rendering</strong> — Explore the scene in real time, powered by Three.js</li>
</ul>
<h2>🛠 Tech Stack</h2>
<ul>
  <li><strong>JavaScript</strong> — Application logic and interactivity</li>
  <li><strong>Three.js</strong> — 3D rendering and scene management</li>
  <li><strong>HTML</strong> — Application entry point and document structure</li>
  <li><strong>CSS</strong> — Styling and layout</li>
</ul>
<h2>🚀 Installation</h2>
<p>Clone the repository and navigate to the project directory:</p>

```bash
git clone https://github.com/AdamFeher3/solar-system-three.js.git
cd solar-system-three.js
```
<h2>Run Locally</h2>
<ol>
  <li>Start a local HTTP server using your preferred tool, such as <strong>VS Code Live Server</strong>, Python's built-in HTTP server, or another development server of your choice</li>
  <li>Open the local URL provided by your server in a browser</li>
</ol>
